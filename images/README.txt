HOW TO CHANGE IMAGES

images/products/    fiber-laser-cutting.jpg, cnc-plasma-cutting.jpg, shearing-press-brake.jpg,
                    plasma-cutter.jpg, welding-machine.jpg, consumables.jpg  (4:3, ~800x600)
images/pages/       home-workshop.jpg, about-workshop.jpg, about-machines.jpg  (4:3)
images/gallery/     gallery-1.jpg ... gallery-8.jpg  (4:3)

Images are cropped to fit (object-fit: cover). Use .jpg; for other formats, edit the src in the HTML / assets/site.js.
